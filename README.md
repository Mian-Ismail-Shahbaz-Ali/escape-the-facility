# ESCAPE THE FACILITY

**A sci-fi survival adventure built with Python for Hack Club StarDance.**

## About the Game

You wake up in an abandoned lunar research facility. The facility has lost contact with Earth, its systems are failing, and its security robots have become hostile.

Explore the facility, search for useful equipment, manage your health and oxygen, and uncover what happened to the missing crew. As you investigate, you'll discover more about a mysterious signal coming from beneath the Moon's surface.

Your mission is to survive, find the emergency access keycard, and escape.

## Features

- Explore different areas of a mysterious lunar facility.
- Collect equipment and manage your inventory.
- Fight hostile robots using different combat options.
- Manage your health and oxygen as you explore.
- Discover logs that reveal the facility's story.
- Solve a riddle and uncover the mystery behind the signal.
- Make decisions that affect your escape.

## How to Play

### Python Version

You'll need Python 3 installed on your computer.

1. Download or clone this repository.
2. Open a terminal in the project folder.
3. Run the game:

   ```bash
   python main.py
   ```

   If needed, try `python3 main.py` instead.

4. Follow the prompts and enter your choices in the terminal.

### Browser Version

A browser-playable version is currently in development. Instructions and a play link will be added here once it is ready.
